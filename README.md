# ESP32-C3 Hardware DMA OLED Benchmark

Высокооптимизированный 3D-бенчмарк для микроконтроллера ESP32-C3 Super Mini и 7-pin SPI OLED дисплея (SSD1306). Код написан на чистом C++/Arduino API без использования тяжелых сторонних библиотек. За счет аппаратного асинхронного DMA SPI достигнута скорость в 2800+ FPS при реальной нагрузке на процессор в 94%-98%.

## Схема подключения (Pinout)

Для достижения максимальной скорости используйте следующие пины:

| Дисплей OLED SSD1306 (7-pin) | ESP32-C3 Super Mini | Функция |
| :--- | :--- | :--- |
| **GND** | **G (GND)** | Земля |
| **VCC** | **3.3V** | Питание дисплея |
| **D0** (CLK) | **GPIO 4** | Тактовая частота SPI |
| **D1** (MOSI) | **GPIO 20** | Данные SPI |
| **RES** (RESET) | **3.3V** | Сброс дисплея |
| **DC** | **GPIO 10** | Команды / Данные |
| **CS** | **GPIO 9** | Выбор устройства (Chip Select) |

## Особенности проекта
* **Оптимизация 3D:** Все вращения куба считаются на лету через целочисленные таблицы Fixed-Point математики (без тормозных float).
* **Прямой рендер буфера:** Очистка памяти и вывод графики происходят 32-битными порциями данных напрямую в регистры.
* **Генератор стресс-нагрузки:** В код встроен фоновый калькулятор шума, который честно загружает процессор на 95%+, не давая ему уходить в простой.
